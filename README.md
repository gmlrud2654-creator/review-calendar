# 📅 후기관리 캘린더

서포터즈·서평단·체험단 안내 문자를 붙여넣으면 마감일·미션·해시태그·제출 링크를 자동으로 정리해 주는 개인용 캘린더입니다.

- 주소: https://gmlrud2654-creator.github.io/review-calendar/
- 저장: Firebase Firestore `families/{uid}/shared/reviewCalendar` (가족 퀘스트 대시보드와 같은 계정·같은 프로젝트, 저장 경로는 완전히 분리)
- 로그인 전에도 이 기기(localStorage)에 저장되고, 로그인하면 자동으로 동기화됩니다.

## 안전장치

1. **3-way 병합**: `기준본(마지막으로 받은 서버 기록)` + `내 화면` + `서버 최신`을 항목·필드 단위로 합칩니다. 옛날 화면을 열어 둔 기기가 최신 기록을 덮어써도, 다른 기기에서 추가/수정한 후기·미션 체크가 사라지지 않습니다.
2. **빈 화면 저장 차단**: 기존 기록이 있는데 화면이 비어 있으면 서버에 저장하지 않고 막습니다.
3. **자동 백업**: 이 기기에 최근 5개 기록을 자동 저장하고, `💾 백업`에서 되돌릴 수 있습니다.
4. **불러오기 전 저장 금지**: 서버 기록을 받기 전에는 저장하지 않습니다.

## 화면

- 월간 캘린더: 마감일별 칩 표시 (완료 초록 / 진행 중 파랑 / D-7 이내 주황 / D-3 이내·지남 빨강 / 날짜 미정 보라)
- 다가오는 마감 D-Day 목록 + 날짜 미정(안내 대기) 묶음
- 전체 / 진행중 / 대기 중 / 완료 필터, 검색
- 후기 카드: 미션 체크(자동 저장), 해시태그 한 번에 복사, 제출 링크 열기, 수정/삭제, 원문 보기

## 테스트

```bash
pip install quickjs
python3 core.test.py
```
